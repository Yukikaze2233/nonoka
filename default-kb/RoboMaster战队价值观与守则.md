# RoboMaster战队价值观与守则

RoboMaster战队价值观&amp;守则

撰写人：

这份文档是在探讨所有RoboMaster队伍会遇到的难题

# 立项

> Alliance在经验中发现，虽然最理想的立项是上交那种，从规则出发，初心就是胜负。但是如果立项的时候考虑上另一个因素，“把某队员送进DJI”，也是不错的。

- 立项时务必珍视现有技术和积累，切莫一直心痒没得到的技术和方案，用好现有的技术储备能在紧张的备赛周期中为整个队伍的进度做好托底，这是让队伍稳定进入国赛的重要支柱
- 在能够保证上一条的基础上，如果队伍想要更进一步，我们要大胆布局新技术，抱持在国赛拿来作为上场方案的决心去攻克他
- 所有人最终都要投入市场证明自身价值，随着AI的爆发，技术日新月异，特别是算法，我们在技术上应该注意行业需求对齐，尽力避免技术过度落后于市场

# 实验室生活

- 把实验室当成自己的家，维护好实验室，特别是自己工位的整洁
- 在垃圾桶满的时候，主动更换垃圾袋。下班的时候看到门口有垃圾，顺手带带走。
- 热情与工作是相辅相成的，正反馈的。在没有任务的时候也要多来实验室。
- 不要让队友孤独地加班，队友也不会让你孤独地加班

# 发展是硬道理

- 队伍与队员是要寻求发展，不断进步的
- 队伍相比于前一年的进步，很大程度取决于留队队员
- 从责任的角度出发，一年制队员是对队伍发展的不负责
- 队伍给队员带来了个人的进步和发展。从道德角度，个人应该回馈队伍，让战队取得进步。
- 这引出来了一个问题，如果已知一个人留下的概率不大，我们应该培养他吗？
- **让一个人发展的从来不是他不行、他不太可能留下的断言和偏见，老队员的这种断言尤其有杀伤力**。如果他还待在队伍里，请抱持着理想主义去尊重和培养他，如果每个老队员都能做到，其实这不会占用个人太多的精力。如果经过队长团审慎的判断，队员不适合在这赛季继续留下，请尽快劝退。

# 人品

- 一个不靠谱但技术力出众的队员应该让他留下吗？
- 警惕那些给出承诺、包揽研发任务但又常常不实现、借口拖延的“高技术力”队员，**严格且严酷的执行“事不过二”原则**！历史无数次证明，这样的人只会损害战队，甚至让一些进度完全受制于他们的心情。即使最终看起来功过相抵，也会伤害队伍的氛围、渴望机会的新人的热情。
- 每个队员应该约束好自己的言行，管理层需要做好引导和约束，更要约束好自己

# 摸鱼、工作与成绩

- 不要等到打完比赛再为了自己的不够努力而后悔,也不要觉得当前取得的成绩就很好了而开始摆烂找乐子(；′⌒\`)
- 不要在实验室玩游戏。主要这会给刚进队的新队员不好的影响
- 空闲的时候，多关心一下队友，可以帮助一下队友
- 有一些工作是不得不分配的，因为有能力的人没有无限的时间和精力。分配出去的工作有可能不如不分配，因为接手工作的人的能力是有限的。
- 实际上，在备赛期间的工作时长、认真程度、效果，已经可以得出最终的比赛成绩了。但每个人都是打完比赛之后再后悔
- 上交提到，“想赢的念头只能在队长团心里”，这是因为没有办法让大家都想赢。如果不想赢的人在一个想赢的队伍里，那他体验到的压力应该是很大的。
- 个人工作的格局可以分成几类：**为了自我的利益**、**出于责任心**、**出于集体荣誉感**

  - 为了自我的利益：只在乎自己学的技术，不在乎自己的兵种的表现，不care规则
  - 出于责任心：努力把自己的兵种做好
  - 出于集体荣誉感：从战队的角度出发思考问题，发现队伍存在的问题会去解决
- RM是最接近于打仗的比赛，也体现出了“不想当将军的士兵不是好士兵”

# 技术问题

- 退役不代表建议权，退役队员的服役时间不见得比现役队员长。不要对退役队员有个人崇拜。
- 对待问题要有自己的思考和判断，首先要能坚定自己的主张，尝试性去说服对方，其次要能虚心理解和接受对方的见解。
